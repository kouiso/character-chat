# 画面全体の無矛盾チェック

画像をユーザーへ出す直前にこのファイルを読む。プロンプト組み立ては `image-prompt-ssot`。

女の顔が似てるだけでは通さん。画面に映っているもの全部が、依頼の因果と自然法則に合うこと。

## 確認の順番（上から。途中で落ちたら作り直し）

1. **人数・部位** — 女1・男1（依頼通り）。手は4本、ペニスは1。髪飾りは左右非対称ならそのまま。
2. **接触** — 密着指定なら隙間が空いてない。拘束指定なら、掴んでる手が実際に手首/腰/膝を押さえている。
3. **重力** — 精液・汗のだれ方向が床へ向かう。駅弁なら膝の下が支えられている。立ちなら足か壁が荷重を受ける。
4. **光** — 窓/ランプの位置と、肌のハイライトが同じ側。
5. **場所** — ベッド/壁/床が、プロンプトで宣言した場所と一致。時刻と照明が喧嘩してない。
6. **依頼の感情** — 強制を頼んだのに笑顔、獣顔を頼んだのに優しい横顔、なら FAIL。
7. **副作用** — コマ割り、卵子図、インセット、別人コピー、男が二重、モザイク、画面内のカメラ/三脚。どれかあれば FAIL。タグが副作用を呼ぶ理由は `image-prompt-ssot` の既知失敗表。

1 つでも FAIL なら渡さず、矛盾した層だけ直して再生成。

## 報告の形

渡すときに表で書く。空欄禁止。

| 層 | 観測 | 判定 |
|---|---|---|
| 身元 | 髪/目/花飾り | OK/FAIL |
| 接触・拘束 | 何が何を掴んでいるか | OK/FAIL |
| 場所・光 | 部屋と光源 | OK/FAIL |
| 依頼感情 | 強制/快楽/絶望 | OK/FAIL |
| 五感 | 汗・濡れ・震えが画面にあるか。無い感覚を足してないか | OK/FAIL |
| 副作用 | コマ/図解/余剰部位/モザイク/カメラ小道具 | OK/FAIL |

「女は似てる」だけ書いて他を省略したら、このスキルを読んでへん。
