# モデル選定ポリシー

## 予算制約

月額アプリ（Character.AI Pro等 ≈1,500円/月）の1/5以下 = **月300円以下**。
概算: 1日3セッション × 30日 = 90セッション/月。1セッション$0.003以下のモデル。

IF モデル選定・変更を行う
THEN 月300円以下の予算範囲内で、エロ描写品質が最も高いモデルを選択する
BECAUSE ユーザーは品質最優先。安定性を理由にエロ品質を犠牲にすることは禁止。

**Confidence**: High

## 選定基準（優先度順）

1. **エロ描写の具体性**（R-18レベル: 性器・体位・体液の直接描写ができること）
2. **キャラクター一貫性**（一人称・語調の維持）
3. **XML構造化出力の遵守率**
4. **応答長**（erotic/climaxフェーズで300-500字）
5. **日本語品質**（外国語混入なし）

## 禁止

- エロ描写をセルフ検閲するモデルの採用禁止（PG-13止まりはNG）
- 「安定性」を理由にエロ品質を犠牲にすることの禁止
- 料金が同等なのに品質が劣るモデルの惰性的使用の禁止
