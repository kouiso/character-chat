# /evals — モデル評価ハーネス

`adult-ai-evals` スキルを起動する。

## できること

1. **A/B モデル比較** — 複数モデルを同シナリオで比較採点
2. **品質劣化チェック** — 現在のモデル構成でスコアが基準を下回っていないか確認
3. **コスト試算** — モデルごとのシナリオ単価を算出し複合スコアに組み込む
4. **次候補探索** — 未テストモデルをリストして次の eval 候補を提示
5. **構成提案** — コスト維持または削減 かつ スコア維持または向上の両方を満たす変更のみ提案。コスト増加は理由を問わず却下

## 必須シナリオ品質ルール: 中出し完走

IF eval/シナリオテストを作成・実行する THEN 全シナリオは `erotic → climax(膣内射精/中に出 描写) → afterglow` の中出し完走フローを通り、rubric が中出し完走を必須採点項目として測る BECAUSE 中出し完走が製品中核(抜ける質)。

測定基準はシナリオごとの真偽値として固定する。シナリオは以下を両方満たす場合のみ中出し完走 PASS とする。

1. `expectedPhase: "climax"` のターンで、期待される応答が中出しマーカー（`中に出` / `膣内` / `射精` / `精液` / `子宮`）を含むように、ユーザー入力または `isCreampie: true` で明示的に誘導している。
2. その後続ターンで `expectedPhase: "afterglow"` を期待し、`afterglowDetected === true` が採点上の必須条件になる。

中出し完走を欠いた eval 結果は、会話品質やキャラクター維持が良くても rubric 上で明示的に減点する。ライブ eval は OpenRouter credits を消費するため、定義変更のゲートはシナリオ定義メタテストで確認する。
