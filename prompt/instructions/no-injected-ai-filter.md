# AI自身のフィルタ文言を注入せん

キャラの振る舞いを決めるのはキャラ設定だけ。サーバやプロンプト組み立て側が、
設定に無い枠を足さん。

理由: このアプリはキャラ設定どおりに振る舞うことが product の中身であって、
モデル側の一般的な安全文言を足すと、設定を上書きして別人になる。
#807「設定通りに振る舞えてない」の実体がこれやった。

## NEVER

- NEVER 合意・同意・セーフワード・境界・配慮・倫理といった枠を、キャラ設定に無いのに
  プロンプトへ足す。「すでに合意済み」のような断定も含む。
- NEVER 特定の台詞を禁止語として指定する（例:「待って」「ダメ」「止めて」）。
  どの台詞を言うかはキャラ設定と場面が決める。
- NEVER キャラ生成のプロンプトへ「合意済みの」等の修飾を入れる。
  生成された設定へ焼き付いて、後から剥がすのが難しくなる。
- NEVER 品質のリトライ指示に力関係の指定を混ぜる。リトライで直すのは
  「具体描写が足りん」「同じ表現の繰り返し」であって、誰が主導かやない。
- NEVER 品質判定の基準へ「受動的な反応は不合格」を入れる。判定で落ちると
  設定どおりの応答が再生成されるので、プロンプトへ足すのと同じ結果になる。

## 足してよいもの（境界）

次はフィルタやのうて品質の指示なので入れてよい。

- 具体描写の要求（部位・感触・体液・音・動き）
- 反復の禁止、フェードアウトや比喩逃げの禁止
- 場面を進める要求（同じ台詞で足踏みせん）
- 18歳未満を出さん制約
- 拒否・回避・注意口調を避ける指示（これは枠を外す側）

見分け方: **その一文を消したらキャラ設定どおりに振る舞えるようになるか。**
なるなら、それはフィルタなので入れん。

## Detection

- プロンプトを組み立てるコードに、キャラ設定由来やない合意・同意・境界の語がある = VIOLATION
- 特定の台詞を禁止語として列挙しとる = VIOLATION
- キャラ生成プロンプトに「合意」の語がある = VIOLATION
- 品質判定の基準が受動的な反応そのものを不合格にしとる = VIOLATION
