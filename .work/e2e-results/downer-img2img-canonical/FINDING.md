# 知見: 正典アバター下敷き img2img は「髪保持 vs エロ化」の綱引きで窓が無い（2026-07-14）

## 実験
- 下敷き = `.work/tmp/avatars/downer-profile-cs2.jpg`（正典プロフィール・髪白黒スプリットが正しい）
- Novita img2img / waiNSFWIllustrious_v90 / DPM++ 2M Karras / steps32 / CFG5 / 同一seed 424242
- strength を 0.45 / 0.55 / 0.65 / 0.75 で振る（script: `scripts/generate-downer-img2img-canonical.py`）
- コスト: 4枚 ≈ $0.01

## 結果（実ピクセル目視）
| strength | 髪スプリット | エロ化 | 判定 |
|---|---|---|---|
| 0.45 | ✅完璧 | ❌ゼロ（正典ほぼコピー・服・alley） | 使えない |
| 0.55 | ✅保持 | ❌服ポートレートのまま | 使えない |
| 0.65 | ✅保持 | ❌背景室内化のみ・服上半身 | 使えない |
| 0.75 | ❌黒髪に崩壊（銀消失） | △脱ぎ始め・胸露出 | 使えない |

## 結論
- img2img は元画像の**構図に固定**される → 髪が持つのは「服のポートレート」の間だけ。エロ構図に振る strength では髪スプリットが黒に崩れる。**両立する窓は存在しない。**
