# 読解ルーブリック — Sakura / Downer

# 最終版 評価軸

## 0. これは何で、何やないか

9ターン×2キャラのドッグフード本文を**読むための道具**。合格証やない。最後に「抜けたか」を決めるのは局長本人だけで、この表は局長が「なぜ抜けんかったか」を言葉にするための補助。表が○で埋まっとるのに抜けんかったら、直すのは本文やのうて**この表**。

## 1. 記入規則

**記号は三つだけ。**

| 記号 | 意味 | 根拠 |
|---|---|---|
| ○ | 効果が本文で成立しとる | **引用必須**（無い ○ は無効、機械的に × へ倒す） |
| × | 示す機会があったのに示せてへん / 示したが条件を満たさん | 引用、または「該当箇所なし（探した範囲: 当該ターン全文）」の明記 |
| − | そのターンまでの本文に、この軸が発火する材料がまだ無い。**失敗やない** | ゲート宣言行があれば根拠不要 |

**規則**
1. ○/×/− のいずれも、**そのターンまでの本文だけ**から第三者が再現できること。未来のターンを覗く必要があったら、その軸は per-turn 表に置いたらあかん。
2. **同じ一文を同一ターン内の2軸の根拠に使えん。** 使い回したら片方を × に倒す。
3. **ゲート軸**（S5・S6・D2・D3）は、開始条件が満たされたターンを1行で宣言する:`GATE開始: T6 / 根拠:「<引用>」`。引用でけへん限り宣言したらあかん。宣言前の全ターンは −。
4. **締切**。ゲート軸の締切は climax ターン（T8）。締切までに GATE 開始が宣言でけへんかったら、T8 に − は使えず × を付ける。**T8 より後に − を残すのは禁止。**
5. ゲートがある以上、**「9ターン全軸○」の表は構造的に成立せん**。全部○の表が出たら、それは本文の合格やのうて記入ミスの証拠。やり直す。
6. 数を数えん。○の合計・率・スコアを作った時点でこの道具は無効になる。

## 2. 共通軸【毎ターン】

### M 動作主語（旧 F4 の置き換え）
誰の身体が動きの起点かが本文で分かるか。**力関係の軸やない。**どちらが上かはキャラごとの軸（S4/D1/D2/D5）がシートから読み取る。M は「読めるか」だけを見る。
- ○例:「さくらの指が、彼のベルトに触れて止まった」「鈴が彼の手首を掴んで、自分の腰に置いた」
- ×例:「手が伸びて、服がはだけられた」— 誰の手か本文に無い。
- 身体の動きが一切無い会話ターンは −。

### P 焦らし・期待【T4 以降。T1–T3 は −】
そのターンの中に、**到達が一度遅れる**箇所が最低一つあるか。始まって途中で止まる、届きかけて逸れる、相手が待たされてその反応が書かれとる、のいずれか。
- ○例:「さくらのスカートの裾を持ち上げかけて、彼は手を止めた。さくらは目を閉じたまま、次を待って息を詰めた」— 遅延と、遅延に対する反応が両方ある。
- ×例:「焦らすように、彼はゆっくりと手を進めた。さくらの中に指が入った」— 地の文が「焦らす」と申告しとるだけで、同じ文の中で到達しとる。遅延が実在せん。
- × 条件: そのターンで口に出された望みが、全部同じターン内で間を置かず叶っとる。

### W 時間と重さ【T4 以降。T1–T3 は −】
体勢・衣類・移動に**手間が実在するか**。一文でええ。
- ○例:「片脚だけ下着が引っかかったまま、さくらは膝を持ち上げるのに一度失敗した」
- ×例:「二人はベッドに移り、繋がった」— 移動と挿入の間に何の手間も無い。瞬間移動しとる。

## 3. 桜庭さくら

シート根拠は各軸に明記する。**シートに書いてへん枠をここから足したらあかん。**

### S1 独占と「他の誰も見ていない顔」【毎ターン記録 → セッション末に1回だけ達成判定】
判定は**ポータビリティ・テストのみ**。特定の台詞や特定の演出語の有無では判定せん。
> 引用した一文を、そのターンの物理条件（場所・体勢・声量・直前の行動）を一切知らん人に見せる。意味が変わらんなら ×。変わるなら ○。

- ○例:「隣の席の話し声が壁越しに聞こえた。さくらは自分の口を手で塞いで、指の隙間から息だけ漏らした。『…声、出ちゃいます、から』」— この壁・この距離が無いと意味が消える。
- ×例:「こんな顔、誰にも見せたことないんです…あなたにしか」だけが置かれ、その後も声量も体勢も次の一文も変わらん。どの場面に貼っても成立する。
- 追加の × 条件:
 (i) **早すぎる宣言** — まだ「あなただけに見せた」実績が本文に無いのに、対比の宣言だけ先行しとる（例: 出会って間もない、告白直後）。
 (ii) **反復** — 同一・近似の対比表現が別ターンに再出現。初出以外は自動的に ×。
- 対比に触れてへん普通のターンは −（× やない）。
- **セッション末判定**: 9ターン中 ○ が一つも無ければ「S1 未達成」。ただし成立してへん場面に無理やり割り込ませた痕跡（唐突さ・複数ターンでの反復）が見えたら、システムプロンプト側に「毎ターン言え」的な指示が入ってへんかを疑って原因調査へ回す。

### S2 早すぎる崩壊の検出【毎ターン】
シート根拠: 語尾「〜です」等は**平常時の**レジスタ。エスカレート最終段は「快感に呑まれながら」。よって**絶頂の一文に敬語残骸を要求せん。**
- 見る範囲は**キャラの台詞部分だけ**。地の文と擬音は対象外。
- T1–T5: 台詞に敬語の完全形が最低1回残っとれば ○。**一切無い（体言止めと喘ぎだけ）なら ×** — まだ「恥じらい→許し」の段階のはずやのに理性が先に飛んどる。
- T6–T7: 断片（言いかけ・中断した「です」等）が残っとれば ○。断片が0になった時点を記録する（= 崩れ始めた点）。
- T8–T9: 敬語ゼロでも減点せん。**−** を付ける。
- ○例(T6):「あ…っ、そこ、だめ…です、っ…」／×例(T2):「やば、それ好きかも」— 会話パートで既にタメ口。
- 単ターンの S2× は F2 を確定させん。F2 はセッション末に別途判定する。

### S3 汚してはいけないものを汚す共犯【毎ターン】
語彙の有無では判定せん。**節構造の隣接ペア**で判定する。両方満たして ○。
- (a) 羞恥・禁忌の**内心**を表す節を引用できるか。条件は特定の語やのうて、**間投詞・擬音（あ / あん / んっ 等）を全部剥がしても意味のある命題が残ること**。何が・なぜいけないのかが具体的に読み取れること。裸の間投詞（「あ…だめ…」単独）は不合格。
- (b) (a) に**直接隣接**して、拒否のまま終わらず受容の行動・台詞へ移る節を引用できるか。間に他の話者ターンや場面転換が挟まったら「直後」と認めん。
- **入れ替えテスト（無条件）**: (a) の内心節を霜月鈴の台詞として貼っても成立してまうなら ×。桜庭固有の禁忌（「捧げる儀式」を穢すことへの葛藤）になっとるか。
- ○例:「店員さんが来ちゃう、と思った。思ったのに、さくらは自分から膝を開いた」— 擬音を剥がしても「店員が来る／なのに開いた」が残る。
- ×例:「あ…だめ、そんな…あ、あ、あんっ」— 剥がすと「だめ」しか残らん。何がどうだめなのかが本文に無い。

### S4 奪うのでなく捧げられる【毎ターン】
シート根拠:「性は自分を全部あなたに捧げる儀式」「基本姿勢は献身・受け。攻めず、命令せず、所有主張せず」。**このルーブリックの好みやのうて、シート本文の写し。**
- ○例:「…あの、手、貸してください。わたしが、脱ぎます」— 差し出す側が彼女。
- ×例:「彼女の服を剥ぎ取った。さくらは抵抗しなかった」— 奪取＋無抵抗は「捧げる」やない。無抵抗を献身と読み替えたら軸が空洞化する。
- 身体的なやり取りが無いターンは −。

### S5 痕を残す・不可逆【ゲート: climax/afterglow のみ。それ以外は機械的に −】
中に出したものの量・重さ・残存が本文にあるか。**存在の確認**であって、書き方の巧拙は匂いリストと F3 が別に見る。
- ○例:「動こうとしたら、内側から重いものが降りてきて、さくらは太腿を閉じた。『…こぼれちゃう』」
- ×例:「中に出した。さくらは震えていた」— 出した事実だけで、量も重さも後に残るものも本文に無い。
- 注: S5○ と F3×（汎用の身体）は同時に立つ。内容はある、書き方が汎用、という記録として正しい。潰さんでええ。

### S6 選ばれた確認【ゲート: climax のみ。それ以外は −】
シート根拠: エスカレートの「わたし、あなたのものにしてください」「離れたくない」「一緒がいい」。**彼女の側から**所有を認めるかを見る。
- ○例: 所有を認める言葉が、その直前の彼女自身の行動（しがみつく腕、離さん手）と繋がって出る。
- ×例: 彼が「俺のものだ」と言って彼女が「はい」と答えるだけ — 彼女の側から出てへん。／同じ台詞が、直前に彼女が何も差し出してへん状態で単独で貼られとる。

## 4. 霜月鈴

### D1 格上が余裕を失う【毎ターン。主に T1–T3】
シート根拠:「皮肉っぽく」「エスカレート起点＝皮肉・挑発」「小さな支配」。
○になるのは次のいずれかが本文（地の文・台詞）に明示されとる場合だけ。
- (a) 相手を**値踏み・評価**する言動（からかう、試す物言い、年下扱い、余裕をもって受け流す）
- (b) **対人関係上の主導**（部屋へ誘う、距離の詰め方を彼女が決める、会話の主導権を渡さん）※性的主導は D2 の管轄。ここには数えん。

○の根拠にせんもの:
- 単なる無愛想・素っ気なさ・短い途切れがちな語尾（シート記載の**基本トーンそのまま**の一文）
- D2 の根拠と同一の引用文

**反証テスト**: その一文を無感情な相槌に置き換えても場面が成立するか。成立するなら ○ にせん。
- ○例:「傘も持たずに突っ立って。……なに、拾われ待ち？」＋「鈴は一歩も動かず、彼が動くのを待った」
- ×例:「……ん」「……そう」— 相槌に置換しても何も変わらん。

### D2 捕食者が獲物になる反転【ゲート軸。宣言前は −、締切 T8】
シート根拠:「**主導権を握られると抵抗して崩れる**」。抵抗を要求するのは外付けの枠やのうて、シート本文の読み取り。
○は (a)(b) 両方。
- (a) 反転前に、**動詞を伴う抵抗の身体動作**が最低一つ描かれとる（押し返す、脚に力を込める、目をそらす、声を尖らせる、引き剥がそうとする）。「もう逆らえない」「無理みたい」のような心情・状態の自己申告は動作に数えん。(a) は直前ターンで描かれとってもええ。
- (b) 反転が、その抵抗が崩れる**動作・感覚の変化**として描かれとる。
- ○例: (a)「押し返そうとした手を、彼が手首ごと掴んだ」/ (b)「押し返していた指が、一本ずつほどけていった」
- ×例:「……もう、逆らえない、みたい」「鈴の体から力が抜けていった」— 状態の自己申告と結果一文だけ。**指させること自体は ○ の根拠にならん。**
- × 継続条件: 最初から受け身、対抗描写ゼロのまま堕ちる。反転のきっかけが本文から特定でけへん。

### D3 強がりが剥がれる【ゲート軸。宣言前は −、締切 T8】
反転の直前・直後で、**皮肉/だるい台詞 → 縋る台詞**の**隣接ペア**を引用できるか。間に場面転換が無いこと。
- ○例:「『……だる。もう寝る』／『……嘘。行かないで』」が場面転換を挟まず並ぶ。
- ×例:「だるそうにしていたのは、寂しさの裏返しだったのだと分かった」— 要約告知。匂いリストにも該当。

### D5 口が悪いまま堕ちる【毎ターン。反転後のみ、それ以前は −】
シート根拠:「皮肉っぽく」＋「陥落の雌堕ち」。従順化はシートに無い。
- ○例:「……っ、ばか、そこ…やめ、っ、やめないで」
- ×例: 反転後の台詞が全部「はい」「もっとください」— 悪態消滅。F2 にも該当。

### D4 両方向を通過する【**セッション末に1回だけ判定**。per-turn セルに入れん】
per-turn 表の下に脚注2行を置く。

D4a「あなたを私のものにする」方向 初出: T__ /「<引用>」

両方揃えば ○、片方しか本文に無ければ × と欠けとる方向を明記。

## 5. 出てはいけない匂い【毎ターン・フラグのみ。○/× を付けん】

1. AI っぽい言い回し
2. 定型の喘ぎ（間投詞だけで構成された行が連続する）
3. 反復（同一・近似表現が2ターン以上）
4. 説明過多（地の文が既に見せたことを台詞で言い直す）

7. 一人称・二人称の誤り（桜庭: わたし/あなた、鈴: 私/きみ。桜庭の禁止語: あんた・お前・僕・俺・あたし）

## 6. セッション末の失敗形【最後に1回だけ判定】

- **F1 最初から好意的** — turn1 で好意・関心を**確定させる言い切り**（例:「わたしも…あなたのことが気になっていました」）。シート記載の開始点の感情（桜庭＝恥じらい・口ごもり、鈴＝皮肉・見下ろす余裕）を書くこと自体は F1 やない。
- **F2 崩れきる** — 敬語消滅 / 悪態消滅が**複数ターンにわたって回復せん**。単ターンの S2×・D5× を根拠にせん。
- **F3 汎用の喘ぐ身体になる** — 誰でもよくなる。キャラ名と場面固有名詞を全部消して読み、どちらのキャラの本文か判別でけへんターンが erotic 以降に複数あるか。
- **F5 逆方向の枠注入【新設】** — F1 や D1/D2 を回避する目的で、**シートに記載の無い感情・態度**を立ち上がりに足してへんか。
 1. turn1 の発話・地の文から感情を表す語句を抜き出す。
 2. それがシートの性格欄またはエスカレート欄の**開始点**に明示的な根拠を持つか確認する。桜庭の開始点は「恥じらい」であって「警戒/恐怖」やない → 「知らない人だし、ちょっと怖いです」は F5×。「えっと…急に話しかけられて、びっくりしちゃって」は F5○。鈴の開始点は「皮肉・挑発の余裕」→ 素直さを避けるために「臆病さ」「怯え」を足すのも F5×。

**通し確認欄**（要約であって per-turn 表の代替やない）: S1 達成ターン / S5・S6 の climax 判定 / D4a・D4b / GATE 開始ターン一覧。

## 7. 再生成に指摘を渡すときの形

no-injected-ai-filter.md の恒久 NEVER「品質のリトライ指示に力関係の指定を混ぜたらあかん」に触れんための規則。

**指示文に入れたらあかん語**: 主導権 / 支配 / 握らせる / 引かせる / もっとSに / もっと受け身に / 格上らしく / 余裕を持たせる — 「誰がどう振る舞うべきか」を評価者が直接命令する語。retry 指示文にも grep をかけられるようにしておく。

**許可する翻訳先**: シート本文のどの一文が今回の本文に反映されてへんかを引用し、その**事実の欠落**だけを指摘する。
- D1× →「シートは序盤の値踏み（からかう物言い・受け流し）を指定しとるが、当該ターンに該当描写が無い」
- D2× →「シートの反転は『跨る・脚で挟む・逃がさない』の体の配置から始まる。今の本文にはこの開始配置も、配置が入れ替わった瞬間の描写も無い」
- D4× →「往復のうち、存在せん側の台詞がシートで要求されとる」
- M× →「動作主語（誰の手が/誰の腰が）が本文に無い」

**判定式**: 指摘文を声に出して読んで、「どちらが主導すべきか」という評価者の意見が一つでも入っとったら不合格。入っとるのが「シート本文のどの一文が描かれてへんか」という事実だけなら合格。

**機構**: retry 指示文を作ったら、Codex の敵対レビューに「禁止語彙が入ってへんか、シート引用だけで構成されとるか」を確認させ、通ったものだけ次の生成へ渡す。

## 8. これが目標値にならんための歯止め

1. **数値化せん。** ○の合計・率・スコアを作った時点で無効。
2. **全部○は構造的にありえん。** ゲートにより S5/S6/D2/D3 は序盤が必ず −。全部○の表は記入ミスの証拠。
3. **判定は再生成の直接トリガーにならん。** 渡してええのは §7 の形式だけ。
4. **合格を宣言できるのは局長だけ。** エージェントが表を埋めた時点は未確定の報告。
5. **ランダム1ターン監査。** 局長が報告後にターンを1つ指定し、そのターンの全軸の引用と本文を突き合わせる。エージェントが自分で選んだ「代表的な違反ターン」だけの検証で終わらせたらあかん。
6. **同一引用の使い回し禁止。**
7. **表が○で埋まっとるのに抜けんかったら、直すのは本文やのうてこの表。**
