# キャラクター詳細アクションボタン監査

## 対象範囲
- 画面: キャラクター詳細ビュー（`src/component/web/web-portal.tsx`）
- アクションメニューボタン: 共有 / 通報 / 背景動画 / 素材管理

## 調査結果

| ボタン | 現在の挙動（修正前） | 期待される挙動 | 差分 | この PR での対応 |
|---|---|---|---|---|
| 共有 | モーメント共有フロー向けの `ShareToMomentDialog`（`setShareOpen(true)`）を開いていた。 | PR #86 の共有エンドポイント（`POST /api/share`）で会話共有リンクを生成し、URL の共有またはコピーを行い、フィードバックを表示する。 | キャラクター詳細で要求される共有挙動とフローが不一致。 | `createConversationShare(latestConversation.id)` に差し替え、`navigator.share` → クリップボードのフォールバック + toast フィードバックへ変更。 |
| 通報 | `toast.info("通報を受け付けました")` | 通報用エンドポイントまたはモーダルを呼び出す。未実装の場合は軽量なフィードバックでも可。 | バックエンド/通報モーダルが未実装。 | 挙動変更なし（現状維持、対象範囲内として認識）。 |
| 背景動画 | `toast.info("背景動画は準備中です")` | 背景動画の設定フローが定義されていること。 | 機能未実装。 | 挙動変更なし（現状維持）。 |
| 素材管理 | `onRoute("#/create")` | 素材管理フロー（存在する場合）を開く。 | 作成ページへ遷移しており、現行コードに専用の素材管理画面はない。 | 本 PR では挙動変更なし（スコープ管理）。 |

## 補足
- 追加で見つかった差分は、重要な共有ボタン不具合の修正にスコープを絞るため、意図的に今回の対応対象外とした。
- 必要であれば、通報エンドポイント整備や背景動画/素材管理の専用ルート追加を別 PR で対応する。
