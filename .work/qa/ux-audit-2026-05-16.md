# UX Audit 2026-05-16 (NSFW chat app)

## Method
- Mechanical scan: `rg -n "onClick|onTap|onPress" src` (162 hit).
- Manual verification on primary surfaces: chat, character detail, moments, PWA banner, auth menu.
- Viewport criteria: 375 / 768 / 1280.

## Findings (Phase 1)

### 1) [HIGH] Character detail CTA「素材管理」が create 導線へ誤遷移
- 場所: `src/component/web/web-portal.tsx:749`
- 現象: ラベル「素材管理」だが `#/create` へ遷移。素材管理という意味に対して作成画面遷移は不一致。
- 再現: キャラ詳細を開く → 素材管理クリック。
- 想定: 素材ライブラリ/アセット管理ビュー、または機能準備中トースト。
- 優先度: High
- 修正案: 目的地 route を素材管理に合わせる (`#/assets` 等) かラベルを「作成」に変更。

### 2) [HIGH] Character detail CTA群が本文後段にあり、SPで主要CTA到達にスクロール必須
- 場所: `src/component/web/web-portal.tsx:723-750`
- 現象: 「あらすじ」「キャラクター情報」「greeting」後に CTA が配置され、375px で first viewport 内に主要操作が出ない。
- 再現: 375px でキャラ詳細を開く。
- 想定: 主要CTA(開始/共有/通報)は fold 上部か sticky で常時アクセス可能。
- 優先度: High
- 修正案: CTAバーをサイドバー直下へ移動、SPでは sticky bottom action 化。

### 3) [MEDIUM] 「通報」「背景動画」が実装未完了でも通常CTA見え方
- 場所: `src/component/web/web-portal.tsx:739-748`
- 現象: 実処理なく info toast のみ。ダークパターン寄り(押せるが結果が薄い)。
- 想定: disabled +「準備中」明示 or beta badge。
- 修正案: 非アクティブ状態にし説明 tooltip を付与。

### 4) [HIGH] モバイルヘッダの overflow リスク（会話メニュー項目+headerActions）
- 場所: `src/component/chat/chat-view.tsx:1037-1068`
- 現象: メニューに action が積まれ、SP で縦方向占有増。PWAバナー/トースト同時表示時に主要操作が隠れる可能性。
- 再現: 375px, conversation share enabled, headerActions 多い状態。
- 想定: メニュー高さ制限 + 内部スクロール + 優先順位。
- 修正案: max-h + overflow-y-auto、重要操作を上位固定。

### 5) [MEDIUM] PWA update banner と他 fixed UI の重なり
- 場所: `src/component/pwa/pwa-update-banner.tsx:34-55`
- 現象: fixed bottom z-50。トーストやチャット入力補助パネルと重なりやすい。
- 再現: needRefresh=true かつ下部UI表示中。
- 想定: safe-area / stack manager でオフセット協調。
- 修正案: CSS変数で bottom offset 合成 (`env(safe-area-inset-bottom)` + toast gap)。

### 6) [LOW] User menu logout disabled時に親div click handlerが残りアクセシビリティ曖昧
- 場所: `src/component/auth/user-menu.tsx:89-101`
- 現象: `div role="none"` 側 onClick 条件分岐と button disabled が混在。
- 想定: クリック責務は button 単体に寄せる。
- 修正案: wrapper onClick 削除、button enabled時のみ handler。

### 7) [CRITICAL確認] reloadで会話消失 fix の回帰点
- 場所: `src/component/chat/chat-view.tsx`（会話状態復元経路）
- 現象: PR #97 fix済み想定。今回コード読解では persistence 関連処理は存在するが、E2E再検証未実施。
- 再現手順(要E2E): 会話中に hard reload → 同会話復元確認。
- 想定: 最終会話とメッセージが失われない。
- 優先度: Critical(未検証残件)
- 修正案: playwright 回帰を必須CI化。

### 8) [HIGH] avatar broken 調査観点（データ欠損時フォールバック不足の可能性）
- 場所: `src/component/chat/chat-view.tsx:493-494` 周辺
- 現象: avatar URL 読み込み失敗時の UX 劣化報告あり。
- 想定: 画像失敗時イニシャル/fallback icon。
- 修正案: `onError` fallback と skeleton 一貫化。
