## 4. 地雷（8/17 の分に足す）

### 4-1. ローカル D1 は seed の**後**に character 系 migration を当て直す

`pnpm run db:migrate:local` → `pnpm run db:seed` の順にやると、**seed が旧版のシートを入れ直す**。
migration 0062〜0068 は既存行を UPDATE するだけなので、後から入った行には当たらん。
前任が 12 アーム・275 ターンを旧版で測った罠と同じ形。

```
pnpm run db:migrate:local
pnpm run db:seed
for f in 0062 0063 0064 0065 0066 0067 0068; do
  pnpm exec wrangler d1 execute adult-ai-db --local --file drizzle/${f}_*.sql
done
```

確認: `名前:` 行あり／`彼女` なし／`無愛用` なし／`恥ずかしい時は「〜なの」` なし。

### 4-2. `task`（go-task）はコンテナに入っとらん

pre-push フックが `ci:fast` を呼ぶので exit 127 で push が落ちる。
`npm i -g @go-task/cli` で入る。**`--no-verify` は禁止**やから入れる方で解決する。

### 4-3. 同じ検出器を 2 つ書きかけた

`hasSplitCreampieDeclaration` が既にあるのに気づかず 2 つ目を書きかけて、grep で見つけて撤回した。
**直す前に `grep` で既存を探す。**このリポジトリは同じ問題に 2 回目の手を入れとることが多い。

### 4-4. Cloudflare の D1 write は分類器にブロックされる

`mcp__Cloudflare_Developer_Platform__d1_database_query` の**読みは通るが書きは弾かれる**。
migration は workflow 経由で当てる（上記）。
