# 会話の記憶を編集する（RIT-92）

キャラクター一覧の「記憶を見る・直す」から、キャラと保存済み会話を選ぶ。
追加、内容の編集、固定、削除をD1へ保存する。次の送信のretrieveで最新の行を読み直す。
記憶は利用者・キャラ・会話の組み合わせで分離し、別の会話には自動で共有しない。

## 境界

- 新規・変更は空白だけを拒否し、1,000 UTF-16コード単位まで。長い既存行は読んで短縮できる。
- 文脈は固定、更新時刻、IDの降順に読み、JSONの包み込みで2,000 UTF-16コード単位まで。入らない行はスキップする。
- 記憶は利用者の参考データとして渡す。システムプロンプトは変更しない。実モデルが必ず記憶に従う保証ではない。
- 版番号が一致した編集・削除だけ成功する。同時編集で失敗した入力は保持し、最新内容の確認と明示的な置換を可能にする。
- 削除前に画面内で確認する。別画面で削除された行を読み直した場合、未保存の入力を一時的に残すが保存はできず、明示操作で破棄する。
- 追加は同じIDで再試行し、応答紛失による二重登録を防ぐ。編集したembeddingは無効にする。
- 削除はD1の当該記憶のみ。会話履歴、別の要約、既存生成の監査記録、Vectorize等の連動消去はRIT-94の別スコープ。

## 自動QA項目

| 操作・前提                 | 期待結果                     | テスト                      |
| -------------------------- | ---------------------------- | --------------------------- |
| 一覧→追加→編集→固定→削除   | 同じ会話の最新状態になる     | memory-panel / memory-store |
| 空欄・長過ぎる入力         | 保存せず入力を直せる         | api-memory / memory-store   |
| 長い旧記憶                 | 一覧で読めて短縮できる       | memory-store                |
| 同じ版を二画面から保存     | 一方だけ成功、他方は409      | memory-store / api-memory   |
| 競合後の読み直し           | 編集入力を勝手に消さない     | memory-panel                |
| 別画面で削除後に読み直し   | 入力保持・保存不可・破棄可能 | memory-panel                |
| 別利用者・キャラ・会話ID   | 記憶を返さず変更しない       | memory-store                |
| 編集・削除後にもう一度送信 | モデル入力の記憶が更新される | memory-context              |
| APIの内部エラー            | 詳細を漏らさず再試行できる   | api-memory                  |

実API・本番D1・deploy・実ブラウザ受入確認は、ユーザーの「実装だけ」の指定により対象外。
画像生成はこの変更の対象外。
