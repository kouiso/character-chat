# 返信の塊ごとの予定時刻（RIT-67）

生成処理が分割した塊を、保存時に順番で並べてから予定時刻を付ける。
基準はサーバーの保存開始時刻。本文のUnicodeコードポイント1文字あたり50ms遅らせ、
1つの塊を待つ間隔は最大5秒とする。タグは字数に数えない。
予定時刻は塊ごとに加算するため、後の塊が前の塊より早くならない。

予定時刻は `v2_chunk.scheduled_at` にUnixミリ秒として保存する。
メッセージ・全塊・台帳を同じD1 batchで保存し、途中の塊だけ残さない。
同じターンの再保存は既存の塊を置き換え、その保存開始時刻から再計算する。
空の返事なら塊も予定も増やさない。空の塊の間隔は0ms。

既存行には0を設定するadditive migrationで、すでに読めた返信を待ち状態へ戻さない。
不正な基準時刻や整数範囲を超える結果は、DBへの書き込み前に拒否する。

この変更は保存まで。予定時刻での表示・入力中表示・時計ずれ補正はRIT-69で扱う。
実API呼び出し、本番migration、画面変更は行わない。
