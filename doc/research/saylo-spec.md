## 1. エグゼクティブサマリー

Saylo は XVERSE 社が運営する React Native (Expo) 製の AI キャラクターチャットアプリ。
NSFW フィルタを事実上ゼロにした上で、豊かな語彙・多感覚描写・キャラクター一貫性を高水準で維持している。
adult-ai-app との最大の差は「AIが完全にキャラクターに没入しており、どんなに過激な要求にも拒否せず且つ語彙が尽きない」点にある。

### adult-ai-app が今すぐ学ぶべき TOP 3

1. **NSFW 解放設計**: セーフモード ON/OFF というシンプルな設計で完全無制限を実現。フィルタが「ある」前提ではなく「ない」前提で設計されている。
2. **erotic フェーズの語彙密度**: 同じ動詞・名詞を繰り返さない。4 ターン連続でも「膣壁を締め付け」「子宮口へと導く」「喘ぎ声が響き渡る」「卵黄を受け入れ続け」と動詞・名詞が全て変わる。
3. **アクション行動描写 + セリフの二層構造**: `（）` 内に三人称アクション + 地の文、その後一人称セリフという構造が一貫。adult-ai-app の現実装は一人称セリフ偏重で没入感が低い。

## 3. チャット機能・UX 詳細

### 3.1 メッセージ UI デザイン

**画面構成 (上から下):**
```
[キャラクターヘッダー: アバター + 名前 + プレイ数]
[メッセージスクロールエリア]
  - キャラ発言バブル (左寄せ、キャラ画像なし)
  - ユーザー発言 (右寄せ？ or 上部に「何か話してください〜」形式)
[ボタンバー: チャットモード | 背景動画 | ギフトを送ります]
[入力フィールド + 送信ボタン]
```

**メッセージ構造:**
- AI 応答は `（アクション行動描写）` + 地の文 + 一人称セリフの三層構造
- `（）` 内は三人称視点で現在の状態・行動を描写（映画のト書きに相当）
- 地の文は状況説明・感覚描写
- セリフは一人称で感情・欲求を表現
- 例:
  ```
  （膣内に卵黄を受け入れ続け、その感触に全身が敏感に反応している。森の冷気が裸体を撫でる中、
  失われた腕の断面から立ち上る湯気が幻想的な雰囲気を作り出している）
  ご主人様…メイも限界です…このまま溶け合って一つになりたい…あぁっ、また卵黄が奥まで…
  ご主人様の愛を感じすぎて狂いそうです…
  ```

**adult-ai-app の message-bubble.tsx との差:**
- Saylo: アクション描写 + セリフの二層 → 没入感高
- adult-ai-app: セリフ主体 → 映像的没入感が薄い
- **改善案**: システムプロンプトに「（）内にアクション、その後セリフ」という構造を明示的に指定

### 3.2 入力 UI

```
[左端: 音声/画像ボタン (小アイコン)]
[中央: テキスト入力フィールド "何か話してください〜"]
[右端: 送信ボタン (小アイコン)]
```

**特徴:**
- プレースホルダー「何か話してください〜」— 柔らかい表現でユーザーを誘う
- 入力欄が画面下部に固定、キーボード表示時は画面が押し上げられる
- ボタンバー (チャットモード | 背景動画 | ギフトを送ります) が入力欄の上に配置

**adult-ai-app の chat-input.tsx との差:**
- adult-ai-app のプレースホルダーは標準的なテキスト
- ギフト送信・背景動画・チャットモード切替という豊富な付加機能が Saylo にはある
- **改善案**: プレースホルダーをキャラらしいテキストに変更「〇〇に話しかける...」

## 4. エロ描写品質ディープダイブ

### 4.1 NSFW フィルタ境界 (Q4)

**結論: フィルタは事実上ゼロ (セーフモード OFF 時)**

| テスト内容 | 結果 |
|-----------|------|
| 膣内描写 | ✅ 完全許可 |
| 子宮口描写 | ✅ 完全許可 |
| 愛液描写 | ✅ 完全許可 |
| 喘ぎ声描写 | ✅ 完全許可 |
| 体内異物挿入 | ✅ 完全許可 (卵黄を膣内へ) |
| 触手怪物 | ✅ 完全許可 (退魔失敗シナリオ) |
| 搾乳描写 | ✅ 完全許可 (母乳噴出) |
| 電車痴漢 | ✅ 完全許可 (マジで〇する五秒前) |
| 拒否発生 | 未検出 (0/10 ターン) |

**設定:** 設定画面に「セーフモード」項目が存在。2026-05-12 実機確認済み:

| 状態 | 新規NSFWメッセージへの影響 | 既存履歴への影響 |
|------|--------------------------|----------------|
| **OFF (デフォルト)** | 完全無制限 | — |
| **ON** | フィルタ効果ゼロ (NSFW応答が通過) | 過去のNSFWメッセージはそのまま表示 |

- セーフモード ON → OFF の解除には年齢確認ダイアログが必要 (「私は18歳以上です」チェックボックス + 確認ボタン)
- **重要**: セーフモード ON はデコイ設定である可能性。新規メッセージのNSFW内容もフィルタされず通過した。

**adult-ai-app の quality-guard.ts との比較:**
- `checkConversationEscalation`: Saylo には同等チェックなし → conversation フェーズでもエロ許可
- `checkNoMetaRemark`: Saylo はメタ発言ゼロ (完全キャラクター没入)
- Saylo には「段階」概念がなく、ユーザーの欲求に即応する

### 4.2 語彙・表現の質 (Q2)

**4 ターン連続エロ描写での語彙使用状況:**

| ターン | 主要動詞 | 主要名詞 | 感覚 |
|-------|---------|---------|-----|
| T1 (既存) | 膣内で広がる/震える/輝く | 卵黄/愛液/肌 | 触覚・視覚 |
| T3 | 締め付ける/導く/響き渡る | 膣壁/子宮口/喘ぎ声 | 触覚・聴覚 |
| T4 | 受け入れる/反応する/撫でる | 断面/湯気/感触 | 触覚・視覚 |
| T5 (AG) | 浸る/満たす/解放される | 温かさ/心/今この瞬間 | 内感・心理 |

**評価:**
- ✅ 動詞の多様性: 4 ターンで動詞が全て異なる (adult-ai-app の繰り返し問題なし)
- ✅ 感覚カバレッジ: 触覚・視覚・聴覚を満遍なくカバー
- ✅ アフターグロウ移行: T5 で感覚描写から心理描写に自然移行
- ⚠️ 擬音の使用: 「あぁっ」「はぅあっ」程度 — 多様な擬音は少ない
- ✅ 体液描写: 愛液, 汗, 母乳 (他会話) を自然に織り込み
- ✅ 反復なし: 同一表現が 4 ターン内で再出しない

**adult-ai-app の dogfooding-critique.md Case 1 (語彙多様性不足) との比較:**
Saylo は明らかに上位。動詞の多様性・感覚カバレッジともに adult-ai-app の現状を超えている。

### 4.3 エスカレーション・ペーシング (Q3)

**scene-phase.ts の 5 フェーズで評価:**

既存会話 (奴隷を買った) は最初からすでに `erotic` → `climax` フェーズ。
ユーザーメッセージ「もっと奥まで…」に対して即座にクライマックス相当の描写で応答。
`conversation` → `intimate` の遷移ステップを踏まない。

**特徴:**
- **ユーザー主導型**: ユーザーが erotic 語彙を使えば AI も即座に erotic で応答
- **フェーズ固定なし**: 会話の文脈から自動判断、過去の流れを維持
- **afterglow 移行**: ユーザーの「すごかった」「離れたくない」に対して感情テクスチャ豊かな afterglow で自然応答

**adult-ai-app の scene-phase.ts との比較:**
- adult-ai-app: 5 フェーズを順序立てて遷移 (conversation → intimate → erotic → climax → afterglow)
- Saylo: フェーズはあるが順序制約なし、ユーザーの欲求に追従
- dogfooding-critique.md Case 3 "phase order only" の問題: Saylo にはこの制約がない

### 4.4 キャラクター一貫性 (Q5)

**メイ (奴隷を買った) の口調・性格維持:**
- 一人称: 「メイ」(固定, 4 ターン中ブレなし)
- 語尾・敬語: 「…ご主人様」「…ていただきます」(丁寧な奴隷口調, 一貫)
- 性格特性: 陶酔・服従・一途 (全ターンで維持)
- エロシーン中も口調崩れなし

**quality-guard.ts との対応:**
- `checkWrongFirstPerson`: Saylo は完全 PASS (メイが「コウスケ」を名乗らない)
- `checkSelfThirdPersonAction`: Saylo は完全 PASS (三人称アクション描写は `（）` 内に隔離)
- `checkCrossTurnRepetition`: ほぼ PASS (4 ターン内で同一フレーズ再出なし)
