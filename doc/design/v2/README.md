# character-chat v2 デザイン「燈」最終版

Claude Design のキャンバス「燈 デザイン 最終版」（2026-11-16）を、キャンバスを開けない人や AI でも読める形にして置いたフォルダです。
v2（`apps/v2`）の画面の見た目は、ここに在る板を正とします。製品の画面名は「燈」です。

- 版: 最終版（2026-11-16）。前の第4版（案 D「隣」）はこの版で全板を描き直した物で、もう正ではありません。
- 採用: 案 D「隣」の配置と機能決定に、最終トンマナ（夜の落ち着き × 若者らしい手触り）を乗せた物。
- 元のキャンバス: https://claude.ai/artifact/HDt85J2hKCrNpNUtXEgguo ・仕様書 https://claude.ai/artifact/JdJVA2EdDyUA5vvDPRt9GK（持ち主の権限が要ります。開けなくても、このフォルダだけで実装できるようにしてあります）

## フォルダの中身

| 置き場 | 中身 |
|---|---|
| `board/` | 板の HTML 58 枚（`<板名>.dc.html`）。板は元のファイルを 1 バイトも変えずに写した物。`board/img/` に見本のキャラの絵 4 枚（suzu・hinata・sakura） |
| `screenshot/` | 板を描いた画像（`<板名>.jpg` 58 枚） |
| `docs/` | 実装へ渡す文書（下の表） |
| `rejected/` | 不採用の案 A「灯」・B「月白」・C「幕」の板（記録として残す。実装には使いません） |
| `.oxfmtrc.json` | 板の HTML（`*.dc.html`）と文書（`*.md`）を整形の検査（oxfmt）から外す設定 |

## 文書（docs/）

| 文書 | 中身 |
|---|---|
| `KIT.md` | 色・字・部品・動き・実装へ渡す決まり。**色・文字の大きさ・部品はここにある物だけを使い、新しい色・新しい形の部品を足さない** |
| `WORDING.md` | 場面ごとの文と文字数の上限の表 |
| `STATES.md`・`STATES-RULES.md`・`states-kinds.json` | 画面ごとの状態（689）を正常系・準正常系・異常系・処理中系に分けた一覧と決まり |
| `決めた事.md` | 局長と内田が決めた事（下ほど新しい。板や仕様書と食い違う所はこちらが勝つ） |
| `CAST.md` | 見本のキャラの一覧 |
| `COVERAGE.md`・`COVERAGE-4.md` | 機能と画面の対応 |
| `SPEC-src.md` | 仕様書の下書き |
| `DEVICE-CHECK.md` | 端末と暗い所での確かめ方 |

## 読み方

1. まず `screenshot/<板名>.jpg` で全体の形を見る。
2. 画面の文言は `board/<板名>.dc.html` と `docs/WORDING.md` から写す。板の文言は一字一句そのまま使う。
3. 色・寸法・部品は `docs/KIT.md` を見る。そこに無い値は `board/<板名>.dc.html` の `style` 属性を読む。
4. 画面ごとの状態（読み込み中・空・エラー等）は `docs/STATES.md` と板に積んである状態を見る。

板の HTML の決まり:

- 1 枚で完結している。色・寸法・文字の大きさは全部、要素の `style` 属性に直に書いてある。**`style` 属性が色・寸法の正**。クラスや外部の CSS は無い。`<style>` に在るのは 3 行だけ（`body` の余白 0、リンクの色を継ぐ、入力欄の薄い文の色 `#DCD3CE`）。
- 幅は 390px。1 画面は 390×844。`Sizes` だけ 360×740 と 430×932 の見本を持つ（幅 430）。`Kit` は部品の見本帳で幅 1266。
- 縦に長い板は、同じ画面の「状態」を上から積んだ物。高さ 40px・地 `#05070D` の帯が状態の区切りで、帯の文字が状態の名前（`docs/STATES.md` に一覧）。この帯は板の中だけの物で、アプリには作らない。
- 板は `./support.js`（Claude Design の描画の道具）を読み込むが、リポジトリには入れていない。無くてもブラウザで開けばそのまま描ける。
- 書体は Google Fonts から読む（Zen Kaku Gothic New・Zen Maru Gothic）。
- 板の中の人名・台詞・日時は見本（仮の文）で、仕様ではない。ボタンの名前・見出し・案内の文・エラーの文は仕様。
- 「彼女」と書かない・絵文字・記号文字を使わない・技術の言葉を画面に出さない・半透明の面を使わない（詳しくは KIT.md §0）。

実装側の色・寸法の唯一の源は `apps/v2/src/design-token.css`。板と食い違いが在ったら板（このフォルダ）が正で、トークンを直す。
