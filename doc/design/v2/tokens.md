# 色・文字・余白・部品の値（案 D「隣」第4版）

板の `style` 属性から拾った実物の値だけを書いた表です。ここに無い値を新しく作らないでください。
足りない時は `board/<板名>.dc.html` の `style` を読み、見つけた値をこの表へ足します。

- 出どころ: 見本帳 `board/Kit.dc.html`（部品の節 36 個）と、画面の板 75 枚の `style` 属性。
- 数えた範囲: `DirD-Home`・`DirD-Chat` を除く 76 枚（この 2 枚は色が違う。`README.md` の「色について気をつける事」）。
- 「板の数」は、その値が出てくる板の枚数（76 枚中）。少ない値は使い所が限られる。
- 色の後ろの「地 16.7」などは、見本帳に書いてある背景との差（コントラスト比）。

## 2. 文字

### 2.1 書体
