# 板ごとの状態の一覧

板に積んである順。帯（高さ 40px・地 `#05070D`）の文字をそのまま写した物。
帯の無い板は 1 画面で 1 状態。`Kit` は状態ではなく部品の節なので、節の名前を並べる。
画面を作る時は、ここに在る状態を全部、テストで出せるようにする。
