## 定義
- **正常系**: やりたい事がそのまま通る流れ。はじめての時／ふだん／たくさんある時（長い一覧）／長い名前や長い文。
- **準正常系**（16 回目に「準正常系」から名前を替えた。局長の語に合わせた）: 利用者や周りの都合で起きる、想定内の「うまく進まない」。
  空（まだ何も無い）／入力が空・形が違う／長すぎる・個数の上限／探して見つからない／許可が無い（通知・マイク・写真）／途中でやめる・未保存で戻る・確かめ／取り消し／削除された子・もう居ない子。
- **異常系**: 仕組みの側の失敗。
  読み込めない／保存できない／つくれない（返事・画像・表情・声・4コマ・クリップ・キャラ）／オフライン・つながらない／途中で切れた／一部だけ届いた／中身の一部が欠けている。
- **処理中系**（16 回目に足した。局長 2026-11-16「正常系・異常系・準正常系・処理中系を網羅して欲しい」）: 待っている間の形。
  読み込み中／保存中・足している・削除している・戻している／送っている・返事を書いている／つくっている・描いている／長引いている（時間がかかっています・まだ描いています）／止めたあと。
- 分け方は帯の題から機械で行う（`tools-split/kinds.py`）。`STATES.md` と `states/*.md` の表は、この 4 つの列で作る。

## 画面の種類ごとに要る状態（その画面で実際に起きる物だけ描く）
- 一覧: ふだん／空／読み込み中／読み込めない／長い一覧と長い名前
- 入力・編集: ふだん／欄の下のエラー（空・形）／保存している間／保存できない（入れた物は残る）／未保存で戻る時の確かめ／保存できた知らせ
- つくる物（返事・画像・声・4コマ・クリップ・キャラ・ストーリーの挿絵）: 待つ間／長引く時／つくれなかった時（もう一度）／途中でやめる／一部だけできた時
- 通話: マイクの許可が無い／つながらない／途中で切れた／声が出せない
- 削除: 確かめ／消している間／消せなかった時／（戻せる物は）元に戻す
- 相手がもう居ない: 削除した子が出てくる一覧・会話・アルバムでの見せ方

- 部品は KIT の「空の時／読み込み中／うまくいかなかった時／知らせ／確かめのシート」を使う。新しい形を作らん

## 16 回目（局長「4 つの種類を網羅」）で足した決まり
