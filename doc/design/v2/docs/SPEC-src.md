## つくらない機能

お金・ログイン・他人が絡む物は、あとで足す物であって、捨てた物ではない。

| 機能 | 理由 |
| --- | --- |
| 大人向けの表現を出さない（セーフモード） | 局長の決定 2026-11-13「このスイッチはいらない。大人向け表現ができなかったらこのアプリは意味が無い」 |
| 画像をぼかす | 局長の決定 2026-11-13「ぼかさんでええ」（通知の文を隠す設定は別の物で、残す） |
| コイン・残高 | 使うのは自分だけで、無制限。あとで足す |

## うまくいかない時

- どの画面にも、起きうる状態を用意する：空・読み込み中・オフライン・入力の誤り・つくれなかった・保存できなかった・相手がもう居ない。
- 何が起きたかを、ふつうの言葉で 1 文で言う。技術の言葉・番号・英語は出さない。使う人のせいにしない。
- 入れた物・書いた物は消さない。何が残っているかを言う。
- 次の一手を必ず 1 つ出す（もう一度／戻る／あとで）。行き止まりを作らない。
- 会話の途中の失敗は、その場に小さく出す（吹き出しの近く・入力の上）。画面全体を覆うのは、画面そのものが開けない時だけ。
- つくる物（返事・画像・声・4コマ・クリップ・キャラ）は、待つ間・長引く時・途中でやめる・一部だけできた時も出す。
- 消す時は確かめを出す。戻せる物（しおり）は「元に戻す」を出す。
- いまのアプリの不具合 12 個は、実装で全部直す。上の表の「直す」と、消す入口・全員ぶんのアルバム・3 つのつくり方がそれに当たる。

## まだ決まっていない事

- 出会うの札の語（同棲／職場／禁断／再会／初対面、甘々／強気／受け身／ツンデレ／そっけない）は仮。
- 声の種類の名前（落ち着いた／やわらかい／明るい／低め／はきはき）は仮。実際の声を聞いて付け直す。
- 見本の文・名前・肩書き（例：「カフェの店員」）は仮。
- 実機と暗い部屋での見え方、動かした時の体感は、まだ確かめていない。
- つぶやきの食べ物・場所の写真を、絵として生成するか、文だけにするか。
- 日記を読んだ事にその子が触れる一文を入れるか。その子の誕生日を記念日の一覧に入れるか。
- 車の画面に着信として出すには、専用のアプリが要る。いまの作りではボタンでの消音と終了まで。
- 作る側で決めた軽い判断は、まだ見てもらっていない（例：AI が覚えた記憶は確かめなしで反映、一覧の札は押すとプロフィールだけ、つくる入口はひとこと欄 1 つ）。
