## 板との食い違い（意図）

- 板の「紹介」「始まり方」「絵の見た目」は設定スキーマに欄が無い。欄は板どおりに残し、値は「入っていません」で出す。
- 「戻している間」は実時間が短く撮影不可（確かめシートのボタン文言が「戻しています」に変わる形）。
- 12 は `_serverFn` 遅延、13 はクライアント遷移時の失敗で再現（SSR 直アクセスでは serverFn を傍受できない）。
- 03 は確かめシートを native dialog へ直した実装で撮り直した。見た目の配置・色・寸法は板どおり。
- 14・15 はレビューで足した異常系で板に無い。形は既存の確かめシート・toast を使い、新しい部品は足していない。
