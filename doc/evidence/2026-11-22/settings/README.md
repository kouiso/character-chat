対象: 板 `doc/design/v2/board/Settings.dc.html`（最終デザイン「燈」）。
実機未確認。ブラウザ 390×844（Playwright・ローカル dev サーバー）で撮影。

## 確認したこと

- 各切替（2〜4 択）は窪みの溝＋選んだ面だけ押せる面＋太字（KIT 6.26）
- 失敗は項目の下に図像＋「保存できませんでした。前の設定のままです。」＋「もう一度」（WORDING 2'）
- 「もう一度」は同じ書き込みをやり直す。新しい選択で古い失敗は巻き戻さない
- 読み込み中は骨組みだけで字は出さない。読み上げは「読み込んでいます」
- 設定はマイの奥なので下のタブ帯は出ない
- GET/PUT /api/settings が `handedness` を往復する（既定 `right`）
