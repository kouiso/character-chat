## 確認したこと

- 大元スイッチはブラウザの通知許可が取れるまで切のまま（許可前・拒否・未対応の 3 帯）
- 切替は押した瞬間に反映し、保存失敗で前の値に戻る。失敗文＋「もう一度」は項目の下
- 「もう一度」は同じ書き込みをやり直す
- 文を隠す ON は例が「燈 / 新しいメッセージがあります」、OFF は名前＋セリフ（push payload と同じ文）
- 通知の設定はマイの奥なので下のタブ帯は出ない（/my の「通知の設定」から遷移）
- GET/PUT /api/settings が通知キー（notifyEnabled 等）を往復する
- 読み込み中は骨組みだけで字は出さない
