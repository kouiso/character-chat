## 撮り方
- `record.mjs`（s1〜s5）と `record-legacy.mjs`（s6）を使う。`verify:ci` と同じ形（`APP_ENV=test`・試験用の固定モデル・手元の D1・BASIC 認証）で `apps/v2` を起動し、実際の Chromium で操作する。
- 画面の上の赤い帯が注記。PR 番号・head・場面・手順を書いている。注記の前に、その手順で画面に出るはずのものを毎回確かめていて、違えばその場面は失敗として残る（`result.json` の `outcome`）。
- 動画は場面ごとの `.webm`。手順ごとの静止画が `-01.png` から順に並ぶ。
- 実モデルは呼んでいない（課金になるため）。返信の文は試験用の固定の文。

## PR 27（head ecb3100）`pr27-ecb3100/`

## PR 28（head 2b1713b）`pr28-2b1713b/`
s1〜s4 は PR 27 と同じ場面を PR 28 の上で確かめたもの。加えて:
| 場面 | 確かめたこと |

## 意図して出しているブラウザのエラー
- s2 の `ERR_CONNECTION_RESET` は、通信を切る細工そのもの。
- s4 の `400 (Bad Request)` は、拒否を返す細工そのもの。
- s6 の `404 (Not Found)` 2 件は、R2 に置いていない画像の最初の読み込みと再読み込み。
それ以外のエラー（hydrate の食い違いなど）は 0 件。
